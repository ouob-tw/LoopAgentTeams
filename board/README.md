# LAT 看板

在一個網頁看所有專案的 LAT 主控：名冊、狀態、目前階段與待決題數，以及收待決題、交付與求助回報的信箱，資料變動後自動更新。電腦與手機共用同一個網址。

連線沒有加密，只應在內網或私人網路使用。

## 安裝與使用

安裝、啟動、配對、背景常駐、自訂樣式與更新，見[使用說明](../docs/lat-board.md)。本檔放開發者需要的細節。

需要 Node 22.18 以上（伺服器與建置）、Bun（可省略），以及已安裝的 LAT 技能與它使用的 `uv`、Python。

## 設定

都是環境變數，啟動伺服器與執行主機指令時要一致。

| 變數 | 用途 | 預設 |
| --- | --- | --- |
| `HOST`、`PORT` | 監聽位址與連接埠（也可用 `start` 的 `--host`、`--port`） | `0.0.0.0`、`7100` |
| `LAT_BOARD_LAT_DIR` | LAT 技能目錄 | `~/.agents/skills/lat` |
| `LAT_BOARD_HELPER_COMMAND` | 直接指定輔助工具指令（JSON 字串陣列），看板會在後面加上 `board list` 等參數 | 由技能目錄組出 |
| `LAT_BOARD_STATE_DIR` | 看板自己的狀態目錄（已配對裝置、配對碼、回報的已讀與封存、送出紀錄） | `$XDG_STATE_HOME/lat/board` |
| `LAT_REPORTS_DIR` | 主控回報紀錄目錄，須與 LAT hook 寫入的位置相同 | `$XDG_STATE_HOME/lat/reports` |
| `LAT_BOARD_FALLBACK_SECONDS` | 漏掉檔案變動時，最慢幾秒內補上（從變動到畫面更新）；5 到 60 | `60` |
| `LAT_BOARD_HELPER_TIMEOUT_SECONDS` | 輔助工具多久沒回應就放棄；最多是（上一項 − 1）秒的一半 | `15` |
| `LAT_BOARD_PAIRING_TTL_SECONDS` | 配對碼有效時間 | `300` |
| `LAT_BOARD_CONFIG_DIR` | 看板的設定目錄，放使用者樣式檔 `user.css` | `$XDG_CONFIG_HOME/lat/board` |
| `LAT_BOARD_INJECT_COMMAND` | 傳話用的輸入指令（JSON 字串陣列），看板會在後面加上 `<HCOM 名稱> <文字> --enter` | `["hcom","term","inject"]` |
| `LAT_BOARD_INJECT_TIMEOUT_SECONDS` | 輸入指令多久沒結束就放棄 | `15` |

`XDG_STATE_HOME` 未設定時是 `~/.local/state`，`XDG_CONFIG_HOME` 未設定時是 `~/.config`。

## 信箱

信箱列出啟用中主控還沒被記錄的待決題，以及所有主控的交付（`DONE`）與求助（`HELP`）回報；其他回報只更新名冊上的目前階段。可依時間或依專案排序，選擇記在各自的裝置上。

- 回報要自己按「標為已讀」；已讀狀態所有已配對裝置共用。
- 回報會自動移到「已封存」：未讀的自發出起滿 7 天，已讀的自標為已讀起滿 3 天。封存後仍可開啟全文，但不能移回信箱，也沒有手動封存。回報紀錄檔不會被刪除。
- 已結束的主控只要信箱裡還有它的回報就留在名冊上，全部封存後才消失。

## 回答待決題

在信箱點開待決題，直接在內容區作答：單選、複選、純文字，選擇題可改填「其他」，都可以加備註。送出後由面板輔助工具寫入問題檔並通知主控，效果與在 Herdr 待答面板作答相同；兩邊可以同時使用，同一題先送出的答案算數。

- 送出後該題顯示「已送出，等主控記錄」；主控記錄後從信箱移除，當時正開著就顯示「已記錄」。
- 題目在你開始作答後被主控改過（升版或改內容），畫面改顯示目前的版本並提示，送出會被拒絕，問題檔不會被寫入；你填的文字與備註保留，選項要重選。
- 已經送出過的題目（例如在 Herdr 面板）不能再作答；已結束主控的待決題也不能作答。
- 答覆不符合題型，或輔助工具失敗時，畫面顯示原因，你填的內容留著。
- 答案寫入了但通知主控失敗時，顯示「已送出，但通知主控失敗」與「重新通知」按鈕，所有裝置都看得到。按下才會重送，看板不會自己重送；重送不會改寫答案。重送回報「沒有待送的通知」只表示沒有東西要重送。重送也送不到，或通知失敗時連待送通知都沒留下來，請在聊天告訴主控。
- 經看板送出的答案記在 `sent-log.jsonl`，和傳話紀錄一起顯示在該主控的資訊頁，狀態會從「已送出，等主控記錄」變成「已記錄」；送出後題目被主控改版則顯示「題目已改版」。在 Herdr 面板作答的不在這份紀錄裡。主控記錄後馬上結束的話，看板讀不到它的問題檔，紀錄會停在「已送出，等主控記錄」。

## 資料怎麼更新

伺服器監看面板綁定登記、各主控的問題檔與回報紀錄目錄，有變動才重讀，正常在 5 秒內推到所有開著的頁面。漏掉變動時由保底重讀補上，最慢 60 秒；畫面上的「重新整理」會立即重讀。連線中斷時畫面會提示，並自動重連。

## 傳話給主控

在主控資訊頁的回覆框，或電腦版面底部的指令列（`@名稱 訊息`；不寫名稱時送給目前開著的主控）輸入文字。看板把文字打進該主控 client 的輸入框並送出，不經過 HCOM 訊息，所以主控把它當成你本人在那個分頁打的字。

- 你同時在那個分頁打字時，兩邊的文字可能混在一起送出。
- 送出前會重讀資料，確認主控仍啟用；已結束的主控不能傳話。失敗時畫面顯示原因，文字留在輸入框，不會自動重試，也不會改走別的管道。
- 每次傳話不論成敗都記在狀態目錄的 `sent-log.jsonl`，在該主控的資訊頁可以看到，所有已配對裝置看到的相同。
- 多行文字以一則訊息送出：行與行之間送的是換行字元（LF），最後才送出 Enter（CR）。文字裡的 CR 會先換成 LF，否則會提早送出。
- 畫面寬度 760px 以下，或只有觸控、沒有滑鼠或觸控板的裝置：Enter 換行，按按鈕送出。其他情況 Enter 送出、Shift+Enter 換行。輸入法選字時的 Enter 不會送出。

## 版面與外觀

- 電腦版面（寬度超過 760px）：名冊頂端的「«」把名冊收成窄直條，直條上每個主控一個狀態標記與待決題數。點標記開啟該主控且維持收起，點直條其他位置展開；滑鼠停留或觸控長按標記會顯示專案、主控名稱、狀態與目前階段。
- 名冊與信箱的右邊界可以拖曳調整寬度，連按兩下還原。名冊 170 到 440px、信箱 260 到 720px；視窗較窄時另外不超過視窗寬度的 30% 與 42%。
- 「設定」（電腦在名冊頂端，手機在頂端列）可以切換深色與淺色主題，並調整整體大小（80% 到 150%，文字與間距一起縮放，可還原預設）。淺色主題是白底黑字、不用半透明，狀態靠形狀分辨：▲ 等你、● 進行中、■ 已交付、□ 已結束。
- 排序方式、名冊收合、兩欄寬度、主題與整體大小記在各自裝置的瀏覽器裡；瀏覽器不允許儲存時一切照常運作，只是不記憶。

### 自訂樣式

把自己的樣式寫在設定目錄的 `user.css`（預設 `~/.config/lat/board/user.css`）。它在內建樣式之後載入，所有已配對裝置重新載入頁面就會套用；刪掉檔案就恢復預設，不需要重啟看板。

顏色、圓角與字型都是 CSS 變數，寫在 `:root` 就能覆蓋，深色與淺色主題都會生效：

```css
:root {
	--accent: #ff8a3d;
	--radius: 2px;
	--sans: 'Noto Sans TC', sans-serif;
}
```

| 變數 | 用途 |
| --- | --- |
| `--bg`、`--surface`、`--line` | 底色、卡片底色、邊框 |
| `--text`、`--muted` | 文字、次要文字 |
| `--accent`、`--warn`、`--ok`、`--danger` | 強調、待決與求助、交付、錯誤 |
| `--status-waiting`、`--status-working`、`--status-delivered`、`--status-ended` | 四種狀態標記的顏色 |
| `--selected-bg`、`--selected-text` | 選中的控制項 |
| `--radius`、`--radius-pill` | 圓角 |
| `--sans`、`--mono` | 字型 |

只想改其中一個主題時，用 `:root[data-theme='light']` 或 `:root[data-theme='dark']`。內建淺色主題的顏色在白底上的對比都不低於 7:1；自己覆蓋的顏色不會被檢查。

## 開發與測試

```bash
bun run dev -- --host 0.0.0.0 --port 7110
bun run check
bun run test        # 先 build，再以暫存目錄與假的輔助工具啟動伺服器
```

測試不讀寫真實的 `.lat/`、綁定登記或回報紀錄，也不會對真實的主控輸入文字或送出答案。測試伺服器使用 7110 起的連接埠，可用 `LAT_BOARD_TEST_PORT_BASE` 更改。

封存的期限用看板的時鐘計算。測試以 `LAT_BOARD_CLOCK_FILE` 指定一個檔案，內容是一個 ISO 時間，看板就把它當成現在；沒有設定或檔案讀不出時間時用系統時間。
