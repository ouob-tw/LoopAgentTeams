# Triage Labels

The skills speak in terms of two category roles and five state triage roles. This file maps those roles to the actual label strings and colors used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Color     | Meaning                                  |
| -------------------------- | -------------------- | --------- | ---------------------------------------- |
| `bug`                      | `bug`                | `#d73a4a` | Something isn't working                  |
| `enhancement`              | `enhancement`        | `#a2eeef` | New feature or request                   |
| `needs-triage`             | `needs-triage`       | `#FBCA04` | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | `#D4C5F9` | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | `#0E8A16` | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | `#1D76DB` | Requires human implementation            |
| `wontfix`                  | `wontfix`            | `#FFFFFF` | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the right-hand columns to match whatever vocabulary you actually use. Keep the colors fixed so every repo looks the same.
