# QA 在看板上測試：取得與歸還測試登入

要在正式看板（7100）做端到端測試時，不要用使用者的密碼，改用測試用登入（反饋庫 #208）。它看得到全部，只能操作自己建立的 Agent，到期自動登出。完整規則見 `docs/lat-board.md` 的「測試用登入」。

## 取得

QA 自己沒有主機指令的權限時，向主控要；主控在主機的 `board` 目錄發一組，把網址交給 QA：

```bash
bun run board test-login --hours <預計時數，最多 24> --label <QA 名稱或票號> --url http://<主機>:7100
```

- 網址只能用一次，交出前不要自己打開。
- 時數照預計測試時間給，不要一律給 24 小時。

QA 用瀏覽器打開網址、按「以測試裝置登入」。看板上方出現「測試裝置」標記才算登入成功。

## 使用

- 要操作 Agent 時，從「新建主控」或 Herdr 分頁的「開新 Agent」自己建立；別人的 Agent 只能看。
- 被拒（按鈕停用或 API 回 403）是預期行為，不是看板壞掉，不要找繞過的方法。

## 歸還

測試結束就收回，不要等到期：

```bash
bun run board revoke <裝置 ID>
```

指令會列出這台測試裝置建立、仍在執行的 Agent。QA 在報告裡寫明哪些該關、哪些要留，由主控或使用者決定是否關閉；看板不會自動關。
